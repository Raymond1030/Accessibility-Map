# 地图标记彩色图标

- 来源：Microsoft Fluent Emoji 的 Flat 版，<https://github.com/microsoft/fluentui-emoji>
- 版本：commit `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`
- 授权：MIT，全文见同目录 `LICENSE`（Copyright (c) Microsoft Corporation）

文件均未修改，只是改成了短文件名。新增图标时从同一 commit 取
`assets/<名称>/Flat/<名称>_flat.svg`（有肤色变体的在 `Default/Flat/` 下），
出发地类型在 `src/ui/markerIcons.tsx` 登记，生活探索类别在 `src/explore/categoryIcons.ts` 登记。
