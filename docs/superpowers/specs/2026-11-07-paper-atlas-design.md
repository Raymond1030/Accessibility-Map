# 生活半径 · 冷白雾蓝地图改版

用户要求：重新设计现有前端，先保存当前版本；参考附图的居中构图、轻盈玻璃卡片和暖色氛围，语言中文或英文，保留现有动画。附件里的 Wandor 提示词是视觉参考，不是改名或实现旅游 AI 的需求。

## 设计

采用中文。页面仍叫「生活半径」，完成通勤比较、生活探索和多点可达性三项既有任务。保留 React 18 + TypeScript + Vite 和现有状态管理。

用户后续明确要求「不要黄色」，最终配色为冷白 `#f7f9fa`、深灰 `#25343d`、灰蓝 `#6d7c85`、雾蓝 `#537d99`、浅边线 `#dce4e8`，地图用青色、蓝紫和深蓝区分。取消米黄底、棕黄文字和地图 sepia 滤镜。中文标题和正文用本地微软雅黑 / 苹方，英文品牌衬字用 Georgia。避免依赖外部字体。

构图：简洁顶栏 → 居中标题和两行说明 → 可选择场景的玻璃入口卡 → 横向展开的动态深圳地图 → 丰富使用说明。核心签名是原有真实地图故事融入冷白雾蓝首页，而不是增加无关旅游地标视频。

用户后续要求丰富底部介绍：采用带图标的三步上手、三张场景示意卡（通勤/见面/探索）、三个可直接进入实际功能的按钮，以及可展开的常见问题。场景图明确标为示意，不伪装成计算结果。

入口卡用三个可访问的场景按钮、对应说明和真正进入目标功能的 CTA。没有虚假 AI 输入框。右上角始终可直接进入地图。地图保留四幕镜头、真实区域计算、进度条、暂停、重播、加载/失败提示、署名与减少动态效果设置；改成冷白浅底。

工作区统一冷白雾蓝、圆角、清晰选中态和输入框。保留所有业务算法、现有面板、地图图层、错误状态和移动端抽屉。

## 验收

- 旧源码含未提交修改可单独解压运行。
- 三个场景入口和工作区返回首页可用。
- 地图四幕可自动推进、手动切换、暂停与重播；真实等时圈仍计算。
- 1440px 桌面、768px 平板、390px / 320px 手机无横向溢出。
- 键盘焦点可见，减少动态效果生效，失败状态仍可重试。
- 类型检查、生产构建、现有测试；如基线已有失败，区分并记录。
